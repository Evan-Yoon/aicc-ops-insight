# Project Plan

## Goal

Build a portfolio-ready AICC operations insight analysis based on CLOVA AiCall references, public customer support data, and competitor metrics.

## Work Order

1. Collect source references in `data/sources.csv`.
2. Collect competitor metrics in `data/manual/competitor_metrics.csv`.
3. Classify customer support inquiries into AICC operation categories.
4. Score operational KPIs.
5. Benchmark competitors.
6. Export final summary files under `outputs/final/`.
