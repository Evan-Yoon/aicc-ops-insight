Why AICC

NAVER Cloud AI Solution 운영 직무는 AI PaaS 상품의 고객 문의, CS 운영 현황, 경쟁사 동향, 품질 평가를 관리해야 한다. CLOVA AiCall은 고객센터 운영·상담 자동화·상담원 연결·품질관리와 직접 연결되는 상품으로, 공개자료 기반 운영 지표화 프레임 설계 대상으로 선정했다. 또한 KT, LGU+, SKT/SK AX 등이 수주액·고객사 수·Auto QA 기능 등 공개 지표를 적극 제시하고 있어 경쟁사 동향 모니터링 관점에서도 분석 가치가 높다고 판단했다.

Analysis Design
① 고객 문의 데이터 구조화
  • 공개 고객지원 데이터 29,872건 활용 — Bitext Customer Support 26,872건 + Support Ticket 샘플 3,000건
  • 문의 유형을 8개 운영 레이블로 재분류: 업무 처리 요청 / 결제·청구 / 계정·인증 / 상담원 연결 / 장애·오류 / 불만·클레임 / FAQ·단순 안내 / 기타
② CLOVA AiCall 운영 구조와 연결
  • AiCall 도입 문의 양식의 상담사 수·평균 콜 수·기존 솔루션·희망 기능 항목을 참고해, 문의 유형을 Main / Global / Repair Scenario와 연결하고 운영 규모·기능 수요 판단 항목으로 해석했다.
  • 장애·불만 유형은 Auto QA 및 Human Handoff 필요도로 분류
③ 경쟁사 공개 지표 정리
  • KT, LGU+, SKT/SK AX의 수주액, 고객사 수, 월 콜 처리량, Auto QA, 상담 어시스턴트 등 공개 지표 수집
  • 실제 시장점유율이 아닌 "공개 운영지표 노출도" 기준으로 비교
